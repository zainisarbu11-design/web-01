# UTS Pemrograman Web 1

Project sederhana tiga halaman HTML sesuai instruksi PDF:
- `index.html`: halaman utama dan dua tautan navigasi.
- `biodata.html`: profil, foto, riwayat pendidikan, dan media sosial.
- `tabel.html`: tabel kegiatan dengan `rowspan`, `colspan`, daftar, dan tautan.

## Menjalankan
Buka `index.html` langsung di browser atau gunakan ekstensi Live Server di VS Code.

## Sebelum dikumpulkan
Lengkapi NPM, program studi, riwayat pendidikan, dan tautan akun media sosial di `index.html` serta `biodata.html`. Foto sumber ada di `assets/foto-profil.jpeg` dan akan diganti dengan versi formal setelah proses edit foto dapat dijalankan.
